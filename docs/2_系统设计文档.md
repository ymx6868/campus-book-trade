## 一、系统架构

### 1.1 整体架构

本系统采用**前后端分离**架构：
┌─────────────────────┐ ┌──────────────────────┐
│ 前端（Vue3） │ HTTP │ 后端（Flask） │
│ ───────────── │ ◄────► │ ───────────── │
│ - 用户界面 │ JSON │ - RESTful API │
│ - 路由管理 │ │ - 业务逻辑 │
│ - 状态管理 │ │ - JWT认证 │
└─────────────────────┘ └──────────┬───────────┘
│
│ SQLAlchemy ORM
▼
┌──────────────────────┐
│ SQLite 数据库 │
└──────────────────────┘


### 1.2 后端分层架构
┌────────────────────────────────┐
│ 路由层（Routes/Controllers） │ ← 处理HTTP请求
├────────────────────────────────┤
│ 服务层（Services） │ ← 业务逻辑
├────────────────────────────────┤
│ 数据层（Models） │ ← 数据库映射
├────────────────────────────────┤
│ 工具层（Utils） │ ← 认证、校验、辅助
└────────────────────────────────┘

## 二、数据库设计（ER图）

### 2.1 实体关系

- **User（用户）** 1 ─── * **Book（书籍）**（一个用户可发布多本书）
- **User（用户）** 1 ─── * **Order（订单）**（一个用户可下多个订单）
- **Book（书籍）** 1 ─── * **Comment（留言）**（一本书有多条留言）
- **Book（书籍）** 1 ─── * **Order（订单）**（一本书可有多个订单记录）

### 2.3 数据表结构

#### users 表（用户）
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK, AUTO | 主键 |
| username | VARCHAR(50) | UNIQUE, NOT NULL | 用户名 |
| password_hash | VARCHAR(256) | NOT NULL | 密码哈希 |
| phone | VARCHAR(20) | NULL | 联系电话 |
| created_at | DATETIME | DEFAULT NOW | 注册时间 |

#### books 表（书籍）
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK, AUTO | 主键 |
| title | VARCHAR(100) | NOT NULL | 书名 |
| author | VARCHAR(50) | NULL | 作者 |
| description | TEXT | NULL | 描述 |
| price | DECIMAL(10,2) | NOT NULL | 价格 |
| condition | VARCHAR(20) | NOT NULL | 成色（全新/九成新/八成新等） |
| status | VARCHAR(20) | DEFAULT 'on_sale' | 状态（on_sale/sold/off_shelf） |
| seller_id | INTEGER | FK→users.id | 卖家 |
| created_at | DATETIME | DEFAULT NOW | 上架时间 |

#### orders 表（订单）
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK, AUTO | 主键 |
| buyer_id | INTEGER | FK→users.id | 买家 |
| book_id | INTEGER | FK→books.id | 书籍 |
| amount | DECIMAL(10,2) | NOT NULL | 交易金额 |
| status | VARCHAR(20) | DEFAULT 'pending' | 状态（pending/paid/completed/cancelled） |
| created_at | DATETIME | DEFAULT NOW | 下单时间 |

#### comments 表（留言）
| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK, AUTO | 主键 |
| content | TEXT | NOT NULL | 留言内容 |
| user_id | INTEGER | FK→users.id | 留言用户 |
| book_id | INTEGER | FK→books.id | 关联书籍 |
| created_at | DATETIME | DEFAULT NOW | 留言时间 |

## 三、API设计

### 3.1 用户模块（成员A负责）

| 方法 | 路径 | 说明 | 是否需登录 |
|------|------|------|----------|
| POST | /api/auth/register | 注册 | 否 |
| POST | /api/auth/login | 登录 | 否 |
| GET | /api/users/profile | 获取个人资料 | 是 |
| PUT | /api/users/profile | 更新个人资料 | 是 |

### 3.2 书籍模块（成员B负责）

| 方法 | 路径 | 说明 | 是否需登录 |
|------|------|------|----------|
| GET | /api/books | 书籍列表（支持搜索/分页） | 否 |
| GET | /api/books/<id> | 书籍详情 | 否 |
| POST | /api/books | 发布书籍 | 是 |
| PUT | /api/books/<id> | 修改书籍 | 是 |
| DELETE | /api/books/<id> | 下架书籍 | 是 |

### 3.3 订单模块（成员A负责）

| 方法 | 路径 | 说明 | 是否需登录 |
|------|------|------|----------|
| POST | /api/orders | 下单 | 是 |
| GET | /api/orders | 我的订单列表 | 是 |
| GET | /api/orders/<id> | 订单详情 | 是 |
| PATCH | /api/orders/<id>/status | 更新订单状态 | 是 |

### 3.4 留言模块（成员B负责）

| 方法 | 路径 | 说明 | 是否需登录 |
|------|------|------|----------|
| POST | /api/books/<id>/comments | 发表留言 | 是 |
| GET | /api/books/<id>/comments | 查看留言列表 | 否 |
| DELETE | /api/comments/<id> | 删除留言 | 是 |

## 五、技术选型说明

| 层 | 技术 | 选型理由 |
|----|------|---------|
| 后端语言 | Python | 团队熟悉，开发效率高 |
| 后端框架 | Flask | 轻量灵活，适合小型项目 |
| ORM | SQLAlchemy | Python事实标准ORM |
| 数据库 | SQLite | 零配置，便于课程作业 |
| 认证 | JWT | 无状态，前后端分离友好 |
| 前端框架 | Vue 3 | 国内主流，学习曲线平缓 |
| UI组件 | Element Plus | 组件丰富，可大幅减少UI开发量 |
| 构建工具 | Vite | 启动快，开发体验好 |

## 六、安全设计

| 安全项 | 措施 |
|--------|------|
| 密码存储 | werkzeug 生成密码哈希，不可逆 |
| 身份认证 | JWT Token，24小时过期 |
| SQL注入防护 | SQLAlchemy ORM 参数化查询 |
| XSS防护 | 前端Vue自动转义 |
| 权限控制 | 用户只能修改/删除自己的资源 |
