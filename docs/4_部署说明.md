# 校园二手书交易平台 - 运行与部署说明

本系统采用前后端分离架构进行开发。以下是本地开发环境的快速部署与启动说明，确保项目可100%复现、可正常运行。

---

## 一、 环境要求
- **后端**：Python 3.8+ 
- **前端**：Node.js 16.x 或 18.x / npm 8.x+
- **数据库**：SQLite (项目启动时自动本地创建)

---

## 二、 后端服务部署 (Backend)

### 1. 进入后端根目录
打开终端（Terminal），导航至后端代码所在的文件夹：
```bash
cd backend
2. 创建并激活虚拟环境（推荐）
# Windows
python -m venv venv
.\venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate

3. 安装依赖项
pip install -r requirements.txt

4. 运行后端主程序
python run.py
运行成功标识：终端输出 。* Running on http://127.0.0.1:5000

说明：系统首次运行，后端会自动在本地创建  数据库文件，并完成表结构的自动初始化映射。book.db

三、 前端服务部署 (Frontend)
1. 进入前端根目录
重新打开一个独立的终端窗口，导航至前端代码文件夹：
cd frontend2. 安装项目依赖
利用包管理器安装 Vue3、Vite、Element Plus 及相关插件：
npm install
3. 开启本地开发服务器
运行 Vite 热更新服务器：
npm run dev
运行成功标识：终端输出 。  ➜  Local:   http://localhost:5173/

代理配置提示：前端已在  中配置了服务器代理（Server Proxy），所有发往  的请求均会自动转发至后端的 ，彻底解决了跨域（CORS）问题。vite.config.js/apihttp://127.0.0.1:5000
