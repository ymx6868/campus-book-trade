## 二、 结对编程总结与体会

1. **Bug 预防率显著提升：** 有领航员在旁边实时观察，打错字（如拼写错误、漏传参数等）在敲代码时就能被立刻纠正，代码合并到 `develop` 后的接口一次性跑通率接近 90%。
2. **知识高度传递：** 两人在全栈技术（Vue3 + Flask）上均通过角色对调得到了实操机会，没有出现某一个人盲区极大的情况。
3. **极佳的团队氛围：** 在代码评审和互相纠错中，我们以 Conventional Commits 提交规范和 PR 机制作为底线卡点，真正体验到了工业级敏捷开发的协同乐趣。
